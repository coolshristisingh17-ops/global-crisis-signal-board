
# Global Crisis Signal Board

A simple, community-maintained information board for major global crises and emergencies.

## What this project does

This repository organizes verified public information about:

- Natural disasters
- Floods and wildfires
- Disease outbreaks
- Humanitarian emergencies
- Climate-related events

## Project Files

- [Active Crises](active-crises.md)
- [Recent Events](recent-events.md)
- [Trusted Resources](resources.md)

## Update Rules

- Use official and reliable sources.
- Add the date when an entry was last checked.
- Do not add unverified social-media claims.
- Keep information factual and neutral.
- This repository is for informational purposes only.
- This is not an official emergency-alert service.

## Contributing

Anyone can help by suggesting verified updates through GitHub issues or pull requests.
