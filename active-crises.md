# Active Crises

This page lists major ongoing crises around the world.

## How to Add an Entry

For each crisis, include:

- Name
- Region
- Status
- Short factual description
- Trusted sources

## Entry Template

### Crisis Name

- **Region:** Country or region
- **Status:** Ongoing / Escalating / Stabilizing
- **Description:** Write 2–4 short factual lines here.
- **Sources:**
  - Source 1 link
  - Source 2 link
